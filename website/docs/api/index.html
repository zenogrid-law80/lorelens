Menu usage

A quick reference for the LoreLens application menu and its repository actions.

Application menu

Use the menu bar to open repositories, manage changes, configure options, and switch the application view.

MenuActions
RepositoryOpen a local repository, clone a repository, and select a recent repository. Entries whose folders no longer exist are removed when the menu opens.
ChangesStage or unstage the selected file, commit staged changes, open file history, and inspect commits waiting to be pushed.
OptionsSelect the shared diff and merge tool, locate its executable, use PATH lookup, select the Lore CLI executable, or configure keyboard shortcuts.
ViewOpen the theme picker, open the command log, and select the UI language.
AccountLog in, log out, and view the current account.

Theme selection

Open View → Theme… to choose the application theme. Select System theme to follow your operating system appearance, or use the Light and Dark tabs to browse the built-in themes.

The preview updates as soon as you select a theme. LoreLens saves your choice and restores it the next time the app starts.

File context menus

Right-click a file or folder in the file browser for filesystem actions. The exact actions depend on the selected item and its repository state.

  • Diff is shown for modified files and opens the configured external comparison tool.
  • Stage / Unstage changes the staging state of tracked files.
  • Discard resets a changed file to the current revision.
  • Move moves a file or folder within the repository.
  • Delete permanently deletes the selected file or folder after confirmation. Repository metadata and symbolic links are protected.

Pending changes menu

Right-click an entry in Pending changes to recover a working copy.

Revert file restores a modified or deleted file to the current committed revision. It discards staged and local edits; a newly added file may be deleted. Unstage removes a staged file from staging while keeping its local changes.

CLI API

LoreLens invokes the Lore CLI with the opened repository as its working directory and passes --repository. Commands that report structured status use --json.

OperationCLI command
Refresh statuslore status --scan --json
Stage / unstagelore stage -- <path> / lore unstage -- <path>
Restore filelore reset --purge -- <path>
Synchronize / pushlore sync / lore push

CLI arguments, raw command output, file paths, and external tool names are preserved as supplied; the UI does not translate them.
